# بُنّ الوادي | Bunn Al-Wadi

Arabic (RTL) landing page for a fictional specialty coffee roastery, built as a portfolio sample.

- Live: https://abdullah-handal.github.io/roastery/
- Roast-level slider that changes the bean, temperature and tasting notes, then suggests a coffee and opens WhatsApp with a ready message
- Plain HTML/CSS/JS, no build step, responsive, keyboard and reduced-motion friendly

The roastery, its story and its prices are invented for demonstration.
